# Hackathon Team Finder

Hackathon Team Finder is a college MERN capstone project intended to help students connect with potential teammates for hackathons based on their skills and interests. The project currently contains the initial client and server structure.

## Technology stack

- MongoDB Atlas with Mongoose
- Express and Node.js (JavaScript)
- React with Vite and plain CSS

## Current status

In development

## Development

- Client: run `npm run dev` inside `client/` (port 5173).
- Server: run `npm run dev` inside `server/` (port 5001).
